# M9 — interactive shell

Final milestone. The kernel no longer self-exits: after `nyx: M8 OK`, `kmain`
calls `shell.run()` (noreturn), which loops reading lines from the unified
console (PS/2 keyboard IRQ + serial via `input.readLine`) and dispatching
built-ins.

## Changes
- `src/shell.zig` (new) — `pub fn run() noreturn`: banner + `nyx: M9 OK (shell ready)`,
  then `nyx> ` prompt loop. Parses first space-delimited token as command, rest as args.
- `src/sched.zig` — added `taskCount()` (next_id) and `liveCount()` (non-done nodes in ring) for `ps`.
- `src/main.zig` — removed the M4 "type a line" interactive self-test (kept `pic.clearMask(1)`
  + the `[M4] keyboard IRQ1 enabled` / `nyx: M4 OK` lines); replaced final
  `exitQemu(.success); hang();` with `shell.run();`. Imported shell.
