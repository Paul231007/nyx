# M9 — interactive shell

Final milestone. The kernel no longer self-exits: after `nyx: M8 OK`, `kmain`
calls `shell.run()` (noreturn), which loops reading lines from the unified
console (PS/2 keyboard IRQ + serial via `input.readLine`) and dispatching
built-ins.

## Changes
- `src/shell.zig` (new) — `pub fn run() noreturn`: banner + `nyx: M9 OK (shell ready)`,
  then `nyx> ` prompt loop. Parses first space-delimited token as command, rest as args.
- `src/sched.zig` — added `taskCount()` (next_id) and `liveCount()` (non-done nodes in ring) for `ps`.
- `src/main.zig` — removed the M4 "type a line" interactive self-test (kept `pic.clearMask(1)`
  + the `[M4] keyboard IRQ1 enabled` / `nyx: M4 OK` lines); replaced final
  `exitQemu(.success); hang();` with `shell.run();`. Imported shell.

## Command set
help, echo, mem, uptime, ps, clear, reboot, plus empty-line and unknown-command handling.

## Verification
`zig build` clean. All earlier markers (M0/M2/M3/M5/M6/M7/M8 OK) still print before the shell.

Boot + shell session (real QEMU serial, fed `help\nuptime\nmem\necho hello world\nps\nbadcmd\nclear\n`):

```
nyx: M9 OK (shell ready)
nyx> help
commands:
  help    -- list commands
  echo    -- print the given arguments
  mem     -- physical frame + heap stats
  uptime  -- timer ticks and seconds since boot
  ps      -- scheduler / task info
  clear   -- clear the screen
  reboot  -- reset the machine
nyx> uptime
up 62 ticks (0 s)
nyx> mem
frames: total=15933 used=1044 free=14889
usable: 62 MiB total, 58 MiB free
heap:   base=0xD0000000 size=4096 KiB
nyx> echo hello world
hello world
nyx> ps
tasks created: 7 (incl. bootstrap)
live in ring : 1
running in bootstrap context (shell)
nyx> badcmd
unknown command: badcmd (try 'help')
nyx> clear
[2J[H nyx>
```

## Notes
- Frame total is 15933 (62 MiB usable) for the -m 64 config — the brief's "~15942"
  is the same ballpark; exact count depends on reserved kernel/mmap frames.
- `mem` "used" rose to 1044 frames after boot (heap's 1024 frames + scheduler stacks/etc).
- `clear` emits VGA clear + ANSI `\x1b[2J\x1b[H` so serial terminals also clear.
- `reboot` pulses 0x64<-0xFE then hlt-loops (not exercised in the headless capture to
  avoid resetting the VM mid-test; `-no-reboot` would halt QEMU anyway).
- Shell runs forever; the 12s qrun timeout ends the capture as expected.
