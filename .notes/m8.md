# M8 — multitasking scheduler (kernel threads + context switch)

## Result
Cooperative round-robin scheduler with kernel threads, PLUS optional timer
preemption. Both proven in QEMU with interleaved task output and a clean exit.

## Boot output (relevant tail)
```
nyx: M7 OK
[M8] spawned 3 tasks; running scheduler
ABCABCABCABCABC
[M8] all tasks finished, back in bootstrap
[M8] spawned 3 PREEMPTIVE tasks (no yields); timer drives switches
xyzyzxxyzxyzxyz
[M8] preemptive tasks finished
nyx: M8 OK
```
- `ABCABCABCABCABC` — cooperative ring; each task prints then `yield()`s.
- `xyz...` (varies per run: `xyzxyzyzxyzxxyz`, `xyzyzxyzxyzxyzx`, ...) — these
  tasks NEVER call yield; only the timer IRQ switches them, so the exact
  interleave shifts run-to-run. That variance is the proof preemption is real.

5/5 runs reached `nyx: M8 OK` with no fault. (The `EXCEPTION 3 (Breakpoint)`
earlier in the log is the expected recoverable M2 int3 self-test, not a fault.)

## Context switch (src/sched.zig, global-asm `switchContext`)
cdecl callee-saved swap:
```
push ebp; push ebx; push esi; push edi   # 16 bytes
mov 20(%esp), %eax    # arg1 old_esp_ptr  (16 pushed + 4 ret addr = 20)
mov %esp, (%eax)      # *old_esp_ptr = esp
mov 24(%esp), %esp    # esp = arg2 new_esp
pop edi; pop esi; pop ebx; pop ebp
ret
```
Arg offsets verified: 20 / 24.

## New-task stack setup
Built top-down from the heap stack (16 KiB), aligned to 16:
`[entry=&taskTrampoline][ebp=0][ebx=0][esi=0][edi=0]`, with `task.esp` pointing at
the saved-edi slot. The first switch pops edi/esi/ebx/ebp then `ret`s into
`taskTrampoline`, which: `sti` (so preempted new tasks run with interrupts on) ->
calls `task.fn_ptr()` -> sets `task.done = true` -> `while(true) yield()` (a
finished task is skipped forever, never falling off its stack).

The bootstrap task is a heap node representing kmain's context; its `esp` is
filled in on the first switch-away (we pass `&prev.esp`). It is a real node in
the ring so `runUntilIdle()` returns into kmain once every spawned task is done.
