## What was built
- `src/pic.zig` — remaps master to 0x20, slave to 0x28 (8086 mode, ioWait between
  ICWs), `setMask/clearMask` (slave port + bit-8 offset for irq>=8), `sendEOI`.
  After remap, masks all lines then clearMask(0) so only the timer is unmasked.
- `src/timer.zig` — PIT ch0 mode 3, divisor 1193182/hz, tick()/ticks()/hz().
- `src/interrupts.zig` — added irq0..irq15 stubs (cli; push $0; push $(32+n);
  jmp irq_common) + irq_common mirroring isr_common but calling irqHandler.
  irqHandler computes irq = int_no-32, calls timer.tick() for irq0, and ALWAYS
  sends EOI. init() now also wires IDT gates 32..47.
- `src/main.zig` — pic.init() -> timer.init(100) -> sti -> hlt loop until >=5 ticks.
