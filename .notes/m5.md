# M5 — Physical Memory Manager

## Result
`zig build` clean. Boot (`bash tools/qrun.sh zig-out/bin/kernel.elf 'hello\n' 8`) serial tail:

```
nyx: M4 OK
[M5] frames: total=15942 used=0 free=15942 (~62 MiB usable)
[M5] alloc: 0x19A000 0x19B000 0x19C000
nyx: M5 OK
```

- total=15942 usable framess ≈ 62 MiB (of the 64 MiB given by `-m 64`; the first 1 MiB + kernel image + multiboot/mmap regions are reserved out). - `used=0` right after init is correct: `stats().total` counts only frames the allocator owns (reserved kernel/BIOS frames are subtracted from `total`, not reported as `used`), so before any alloc `free == total`. - 3 allocs are distinct, page-aligned (0x..000), and land just above the kernel image (~1.6 MiB). After freeing, `free` restores to the pre-alloc value.
