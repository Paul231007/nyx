# M5 — Physical Memory Manager

## Result
`zig build` clean. Boot (`bash tools/qrun.sh zig-out/bin/kernel.elf 'hello\n' 8`) serial tail:

```
nyx: M4 OK
[M5] frames: total=15942 used=0 free=15942 (~62 MiB usable)
[M5] alloc: 0x19A000 0x19B000 0x19C000
nyx: M5 OK
```

- total=15942 usable frames ≈ 62 MiB (of the 64 MiB given by `-m 64`; the
  first 1 MiB + kernel image + multiboot/mmap regions are reserved out).
- `used=0` right after init is correct: `stats().total` counts only frames the
  allocator owns (reserved kernel/BIOS frames are subtracted from `total`, not
  reported as `used`), so before any alloc `free == total`.
- 3 allocs are distinct, page-aligned (0x..000), and land just above the kernel
  image (~1.6 MiB). After freeing, `free` restores to the pre-alloc value.

## Approach
- `src/pmm.zig`: static `[131072]u8` bitmap in .bss covering 4 GiB / 4 KiB =
  1,048,576 frames (1 = used, 0 = free).
- `init(info)`:
  a. `@memset` the whole bitmap to 0xFF (everything used).
  b. Check flags bit 0x40 at info+0; read `mmap_length` (info+44) and
     `mmap_addr` (info+48). Walk entries; for `type == 1` regions, round the
     base up to a frame boundary, free each frame, and bump `total_frames` /
     `highest_frame`.
  c. Re-reserve: first 1 MiB, `[kernel_start, kernel_end)` (from linker syms via
     `@intFromPtr(&kernel_end)`), the multiboot info struct (4 KiB), and the
     mmap buffer itself. Each reserved usable frame is subtracted from
     `total_frames` so `free = total - used` stays consistent.
- `allocFrame()` scans `[0, highest_frame]` for a clear bit, sets it, returns
  `idx * 4096`. `freeFrame(addr)` clears the bit with out-of-range + double-free
  guards. `stats()` returns `{total, used, free}`.
