## Mapping layout
- Page directory: one 4 KiB frame from pmm, zeroed, physical addr = CR3.
- Identity map `[0, 0x4000000)` (64 MiB) → covers full `-m 64` RAM: kernel image,
  stack, pmm bitmap, the page tables themselves, VGA @ 0xB8000.
- 16 page tables (one per 4 MiB), each 1024 PTEs present+rw with `phys == virt`.
- Page tables live in identity-mapped RAM so the CPU can walk them after PG=1.
- `map(virt, phys, flags)`: PDE idx = virt>>22, PTE idx = (virt>>12)&0x3FF.
  Allocates+zeros a new page table if the PDE is absent, installs PTE, `invlpg`s.
- Probe: `map(0xE0000000 -> 0x1AD000, present+rw)` then write/read 0x1234ABCD — OK.

## Page-fault handler (interrupts.zig, int_no == 14)
Reads CR2, prints `PAGE FAULT at 0x.. eip=0x.. err=0x.. [P/W/U bits]`, then
`exitQemu(.failure); hang()`. Fatal for now (no demand paging yet).
