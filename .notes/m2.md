## Files
- `src/gdt.zig` — flat 3-entry GDT (null / code 0x9A / data 0x92, gran 0xC),
  `lgdt` + segment reload via `mov`s and `ljmp $0x08,$1f`.
- `src/idt.zig` — 256-entry IDT, `setGate(n, handler, type_attr)`, `load()`.
- `src/interrupts.zig` — `Frame` extern struct, 32 ISR stubs + common stub,
  `isrHandler`, `init()`.
- `src/main.zig` — wired `gdt.init()` / `interrupts.init()` / `int $3` self-test.
