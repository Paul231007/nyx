Expected sum = 3*(0+1+...+499) = 3*124750 = 374250 — matches.

## Design (src/heap.zig)
- Window: `HEAP_BASE = 0xD0000000`, `HEAP_SIZE = 4 MiB` (1024 frames), mapped
  up-front — one `pmm.allocFrame()` per 4 KiB page, `paging.map(virt, f, 0x3)`.
  High virtual space, no collision with the 0..64 MiB identity map.
- First-fit, address-ordered free list. `Block = { size, free, next, prev }`
  header immediately precedes its payload; blocks tile the window with **no
  gaps**, so the physically-next node is always `b.next` and coalescing is a
  plain merge (with next and with prev) on `free`.
- Alignment: std hands a log2 alignment (`std.mem.Alignment`). We place the user
  pointer at `alignForward(payloadStart + @sizeOf(usize), a)` and stash a
  back-pointer to the owning `Block` in the `usize` slot just before it, so
  `free(ptr)` recovers the header regardless of alignment padding. Tail of the
  chosen block is split into a new free block when leftover >= header + 16.
